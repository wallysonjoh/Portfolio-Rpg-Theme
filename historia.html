2026 — O Despertar

Primeiro Contato com o Código

Tudo começou com curiosidade. O primeiro arquivo HTML aberto no bloco de notas, sem IDE, sem framework — apenas a vontade de entender como as páginas da internet eram construídas. Uma linha de código abriu uma janela para um universo inteiro.

Os primeiros projetos eram simples: uma página sobre um jogo favorito, um formulário que não funcionava direito, um botão que mudava de cor ao passar o mouse. Mas cada pequena vitória alimentava a chama.

HTML5 Bloco de Notas Curiosidade

2026 — A Forja

Descobrindo a Arte do CSS

Com a base de HTML estruturada, chegou a hora de dar cor e forma ao mundo digital. CSS se revelou uma linguagem de design tanto quanto de programação — Flexbox, Grid, animações, variáveis. A transformação de páginas estáticas em interfaces vivas foi uma revelação.

Foi nesta fase que o VS Code foi adotado como forja principal, substituindo definitivamente o bloco de notas e abrindo as portas para as extensões, o terminal integrado e o controle de versão.

CSS3 Flexbox Grid VS Code
⚡
2026 — O Encantamento

JavaScript: A Magia da Interatividade

O JavaScript trouxe vida às páginas. Manipulação do DOM, eventos, funções assíncronas — cada conceito abriu uma nova dimensão de possibilidades. O primeiro projeto com JS funcional foi o Quest Log Theme Zelda, um registro dinâmico inspirado na franquia lendária.

A curva de aprendizado foi desafiadora, mas cada erro debugado foi uma lição gravada na memória. O console.log se tornou um companheiro inseparável das aventuras noturnas de código.

JavaScript DOM Async/Await GitHub

2026 — A Fortaleza

Portfolio RPG: A Grande Obra

A criação deste portfolio marcou uma virada. A ideia de misturar a estética medieval/RPG com desenvolvimento moderno nasceu da paixão por jogos e pela vontade de se destacar. Aqui, cada página é uma masmorra, cada skill é um feitiço, e cada projeto é uma quest concluída.

Three.js, APIs, TypeScript — ferramentas que antes pareciam inatingíveis foram integradas ao projeto com estudo diário e muita determinação. O portfolio é um documento vivo: cresce conforme o herói evolui.
